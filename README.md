# SkyCast – Weather App UI/UX Design 
##  Project Overview
SkyCast is a modern and user-friendly weather application UI/UX design created using Figma. The application helps users check current weather conditions, view daily forecasts, explore weather information for different cities, and customize their weather preferences.The design uses a consistent sky-blue background with beautiful cloud and mountain visuals across all five screens. The interface focuses on simplicity, readability, and easy navigation to provide a smooth user experience.

## Objectives
- To design a modern and visually attractive weather application.
- To display current weather conditions and temperature clearly.
- To provide daily and weekly weather forecasts.
- To show detailed weather information such as humidity, wind speed, and UV index.
- To allow users to explore weather information for multiple cities.
- To create a consistent design across all five screens.
- To improve usability through simple navigation and interactive prototyping.

## Design Highlights
- **Consistent Background:** The same sky-blue background theme is used across all five screens.
- **Modern UI:** Clean layouts with rounded cards and soft gradients.
- **Color Palette:** Blue, white, and light purple shades inspired by the sky.
- **Typography:** Clear and readable text using modern fonts such as Poppins.
- **Weather Icons:** Sun, clouds, and rain icons for easy understanding.
- **Reusable Components:** Consistent cards, buttons, icons, and navigation elements.
- **Mobile-First Design:** Designed for mobile screens with a frame size of 390 × 844 px.
- **Interactive Prototype:** Connected screens demonstrate the app's navigation flow.

##  Features
- **Home Screen:** Displays the current temperature, weather conditions, humidity, wind speed, and hourly forecast.
- **Forecast Screen:** Shows a seven-day weather forecast with temperatures and weather icons.
- **Weather Details Screen:** Displays humidity, wind speed, precipitation, UV index, sunrise, sunset, and air quality.
- **Cities Screen:** Allows users to view weather information for multiple cities.
- **Settings Screen:** Includes temperature units, notifications, location, appearance, and support options.
- **Bottom Navigation:** Provides easy access to Home, Forecast, Cities, and Settings.
- **Consistent UI:** Maintains the same visual style across all five screens.
- **Prototype Navigation:** Enables users to navigate between screens in Figma.
